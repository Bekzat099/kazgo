# KazGo 🏹

«Покемон Го» по-казахски: ходишь по своему городу и собираешь сокровища степи —
домбру, қобыз, ою-өрнек, шаңырақ, адыш… и вещи ещё более редкие.

## Что внутри

- 🗺️ Карта OpenStreetMap с вашим местоположением
- 📍 **GPS-режим** — идёте по городу, собираете предметы в радиусе 30 м
- 🕹 **Демо-режим** — виртуальный джойстик (тест на компьютере / без GPS)
- 📖 Кодекс: 19 предметов, 4 редкости (ади / сәлқән / тарихылы / легендалық)
- ⭐ XP и уровни с казахскими названиями (Ушырын → Батыр)
- 🎯 Ежедневные квесты
- 🔊 Синтезированные звуки домбры (WebAudio)
- 💾 Прогресс хранится в браузере (localStorage)

## Запуск

```bash
cd kazgo
python -m http.server 8412
# открыть http://localhost:8412
```

Подойдёт любой статический сервер: `npx serve`, Netlify Drop и т.п.

## Игра на телефоне

Геолокация в браузере работает только по **HTTPS** (или на localhost).
Варианты: перетащить папку на [Netlify Drop](https://app.netlify.com/drop) → https-ссылка,
или Vercel / GitHub Pages. Ссылку открываете на телефоне, разрешаете геолокацию — и гуляете.

## Как работает спавн

- Карта разбита на клетки 40×40 м. Предмет в клетке определяется детерминированно
  (seed = клетка + день + счётчик сборов), поэтому предметы «живут» на своих местах.
- После сбора клетка пустует 90 секунд, затем в ней появляется новый предмет.
- Радиус мира — 350 м от игрока; гарантированно есть предмет в пределах ~120 м.
- Шанс предмета в клетке ~34%; редкости: ади 55%, сәлқән 25%, тарихылы 15%, легендалық 5%.

## Идеи на потом

- AR-режим с камерой
- Региональные предметы (Алматы — горы, Костанай — дала, Астана — мосты)
- Друзья и обмен
- Босс-события (сарыарка, аки-акыны)
- Мультиплеер/сервер для персистентного мира
